# CI policy templates

These files are reusable starting points for a repository's `.github/workflows/` directory.

Before using one:

1. Replace placeholder commands with commands the repository already runs locally.
2. Pin or review action versions according to the repository's Actions standard.
3. Keep permissions least-privilege.
4. Test pull requests from forks without exposing secrets.
5. Make a check required only after its name and behavior are stable.

The templates establish shape and policy intent. They do not decide the repository's language commands, deployment behavior, secrets, or Project synchronization.
