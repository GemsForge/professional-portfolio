What I shipped

I work full-stack across the enrollment platform — from UI forms and plan-comparison features to API integrations and unit tests — delivering through Agile Scrum with code review and CI/CD.

Accessibility impact

I led the WCAG refactor of a production enrollment application, covering semantic HTML restructuring, ARIA roles and live regions, and accessible patterns in component design. The refactor was my first time owning a cross-cutting technical initiative at ADP — it sharpened my React and TypeScript skills and shaped how I approach every component I build.

Test suite I owned

I took ownership of the enrollment regression suite in Mabl and JavaScript — standardizing naming conventions, extracting shared procedures, and writing Confluence documentation so any engineer can run, extend, or debug the tests without starting over. I also wrote NUnit unit tests for C#/.NET service logic. When I joined, coverage was fragmented; I organized it so the next developer can find and use what's there.

Production support

In a system where enrollment errors affect real employee benefits, I trace issues across the full stack — React UI, REST APIs, PostgreSQL, and SQL Server — using Splunk log queries and local debugging to support production issue resolution and coordinate with the team.
