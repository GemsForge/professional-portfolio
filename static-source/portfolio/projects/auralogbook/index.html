The project

AuraLogbook is a full-stack mood-reflection journal that helps people record emotions, revisit personal history, and explore patterns over time. Users can choose a reflective pathway—Mindful Living, Astrology & Energy, or Faith & Religion—so journaling can align with their beliefs and perspective. They can personalize a profile and explore dashboard context such as mood trends, zodiac-based reflections, and current weather. It is a reflection tool—not a diagnostic or treatment tool.

My focus: connecting a typed frontend to a .NET API, organizing application responsibilities, and handling authenticated workflows.

Inside the implementation

Frontend foundation

A typed client interface with shared state and API-query handling, responsive UI components, client-side routing, and dashboard visualizations. The reviewed app includes session restoration, loading feedback, and expired-session notifications.

Backend responsibilities

The mood controller delegates work to injected mood and statistics services. Authorized actions cover mood-entry creation, retrieval, editing, deletion, and dashboard queries.

Development support

A debug-only endpoint generates sample entries to support development. Setup and environment configuration are documented in the repository.

What this demonstrates

This project demonstrates full-stack product development across authenticated user workflows, API design, layered backend architecture, frontend state management, external API integration, data visualization, and automated testing.

Current state & next steps

In development. The inspected source currently stores user, mood, and zodiac-insight data in JSON files. As the project expands, I plan to move application data to a small database such as SQLite. SQLite and Dapper are declared dependencies, but the migration is future work—the app does not currently persist records in SQLite.

Next: complete and verify a user-facing flow, add screenshots using fictional data, and document the decisions behind the UI and API integration.
