The project

Aura Logbook is primarily a mobile app for recording how you feel, writing a reflection, and returning to your personal history. Its responsive desktop view carries the same check-in and reflection flow onto a larger screen. The refreshed sign-in and home screens lead into mood check-ins, saved reflections, and insights. Reflective pathways—Mindful Living, Astrology & Energy, or Faith & Religion—shape prompts and context. It is a reflection tool—not a diagnostic or treatment tool.

My focus: shaping a calm, usable mobile-first experience and connecting its typed frontend to a .NET API through authenticated workflows.

Inside the implementation

Frontend foundation

The manifest specifies React 19.1, TypeScript 5.8, Material UI 7.1, Joy UI 5 beta, Redux Toolkit 2.8 with RTK Query, React Router 7.6, Axios 1.10, and Recharts 2.15. The app includes session restoration, loading feedback, and expired-session notifications.

Backend responsibilities

The API targets .NET 9. Mood controllers delegate work to injected services, and authorized routes manage mood entries and dashboard data. Development and FIT/Staging use SQLite through Dapper with versioned startup migrations; committed JSON files remain import and local-development seed sources.

Development support

A debug-only endpoint generates sample entries to support development. Frontend tests use Vitest and Testing Library; API tests use xUnit and Moq. Their presence shows test coverage exists, not that the suites have been run or passed for this portfolio update. Setup and environment configuration are documented in the repository.

What this demonstrates

This project demonstrates mobile-first product thinking, responsive interface design, authenticated user workflows, API design, layered backend architecture, frontend state management, data visualization, and automated testing.
