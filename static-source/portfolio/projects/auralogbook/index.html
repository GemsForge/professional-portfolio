Product goals and my contribution

Aura Logbook is a private reflection journal designed for quick phone check-ins and useful review over time. I shaped the product and built its responsive web client, React Native navigation shell, and .NET API.

The engineering work connects authenticated user journeys to mood records, reflections, insights, private photo access, and configurable content. The optional Spotify connection adds listening context while playback stays in Spotify.

Product boundary: Aura supports personal reflection. It is not a diagnostic or treatment tool.

Technical approach

Client delivery

The React 19 and TypeScript web client supports responsive phone and desktop layouts with Material UI, Joy UI, Redux Toolkit, RTK Query, React Router, Axios, and Recharts. A React Native/Expo shell organizes the native destinations.

API and persistence

The .NET 9 API separates controllers, injected services, and user-scoped routes. Dapper repositories and versioned SQL migrations persist journal data in SQLite for Development and FIT/Staging.

Identity and integrations

JWT-protected workflows scope journal and private-media access to the signed-in user. Spotify linking uses OAuth Authorization Code with PKCE; encrypted tokens stay in the API, while the client receives playback and playlist metadata.

Configurable product data

Database-backed definitions keep pathways, moods, colors, prompts, and presentation settings configurable. A debug-only endpoint provides sample entries for development.

Verification evidence: the repositories include Vitest and Testing Library checks for the web client, plus xUnit and Moq tests for the API. The links below show test coverage exists; they do not claim every suite has passed.

Core user flow

The main workflow connects account access, daily entries, saved history, and reflection insights.

  1. Register or sign in

    Authenticate before entering personal journal data.

  2. Record a check-in

    Save a date, one or more moods, and an optional reflection.

  3. Review saved entries

    Browse by date range, then update or delete an entry.

  4. Explore patterns

    Use summaries, charts, and pathway-specific reflection content.

The React Native/Expo navigation shell organizes Today, Log, Journal, and Profile. The paired captures show the responsive React web client.
