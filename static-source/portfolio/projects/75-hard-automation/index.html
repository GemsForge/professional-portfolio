75 Days of Discipline

A personal accountability system that turns daily 75 Soft commitments into visible progress through Apple Shortcuts, Notion, and automated metrics.

Independent workApple Shortcuts · Notion API · Daily accountability

The friction

Showing up every day is harder when the challenge depends on memory, motivation, and scattered notes. I needed one repeatable check-in for completion, water, exercise, personal growth, and reflection.

I did not want to pay for another specialized app without knowing whether it would support the logging details I actually needed. Notion was the most practical logbook for me: flexible enough to capture daily details, structured enough to support metrics, and already part of my workflow.

The purpose

The 75 Soft Challenge became my training ground for something bigger—the Murph Challenge. I knew that if I wanted to hold myself accountable, I needed a visual metrics tracker that would make my consistency visible and keep me motivated.

The resulting Notion records let me review completion, exercise, hydration, personal growth, reflections, and dates over time through a visual chart.

The technical solution

The Log Discipline Day folder organizes 13 Shortcuts into a daily accountability system. Prompts and response helpers stay separate from the logging and API layer, keeping the daily experience simple while the stored record remains structured.

The end-to-end flow is: prompt collection → response dictionary → Notion request → daily database record → progress review.

Log Discipline asks for a log date, runs Get Discipline Response, reads disciplined and undisciplined values from a dictionary, conditionally combines reflection text, stores a Reflection Response variable, and references water-intake follow-up.

Shortcut inventory

The reviewed folder contains 13 named Shortcuts, separating entry points, prompts, response helpers, logging, and the Notion request builder.

  1. Combat Ready - Last 20 Lbs — primary shortcut entry point.
  2. Open Finch All — opens the Finch companion workflow.
  3. Get Morning Message, Dynamic Morning Message, and Get Milestone Message — prompt context.
  4. Log Discipline, Get Reflections Response, and Get Discipline Response — daily responses.
  5. Get Read Bible Prompt, Get Water Intake, and Get Exercise Response — personal growth and completion inputs.
  6. Discipline Http Request — centralizes the Notion API request body.
  7. Log Discipline Day V1 — earlier logging workflow retained in the folder.

Notion request structure

Discipline Http Request receives a dictionary, extracts values for Disciplined, Exercise, Water, Faith, Reflection, and Date, then builds a Notion page request.

The request body includes a date property, a Goal Tracker relation, and structured properties for Disciplined, Exercise Completed, Water Intake, Personal Growth, and Reflection. Database and relation identifiers are intentionally not published.

Application dependencies

  • Apple Shortcuts — runs prompts, helper workflows, conditional logic, variables, and the HTTP request.
  • Notion API — receives the structured daily page request.
  • Notion workspace and database — stores discipline records and the Goal Tracker relation.
  • Notion API integration permissions — required to access the target database.
  • Apple Calendar or date context — supports daily scheduling and date-based accountability.
  • Finch — referenced by Open Finch All as part of the surrounding accountability workflow.

Intended benefit

The system reduces the mental overhead of repeating a daily check-in, makes completion signals consistent, and preserves a searchable record of discipline, exercise, water, personal growth, reflections, and dates.

It gave me one reliable place to see whether I was following through, where I was falling short, and what needed to change the next day.

Evidence & current limits

The Shortcut folder and editor review verify the names and behaviors described here. Public screenshots, exported Shortcuts, synthetic request/response examples, and a full run history have not yet been attached.
