75 Hard automation

A daily discipline workflow that gathers completion signals, reflections, exercise, water, faith, and date context, then records the structured result in Notion.

The friction

A multi-requirement daily challenge creates repeated cognitive overhead: remembering each requirement, collecting responses, writing reflections, and recording the day consistently. A manual checklist can become another task to maintain.

The technical solution

The Log Discipline Day folder organizes 13 Shortcuts into a daily accountability system. The workflow separates prompts and response helpers from the logging and API layer.

Log Discipline asks for a log date, runs Get Discipline Response, reads Disciplined and Undisciplined values from a dictionary, conditionally combines reflection text, stores a Reflection Response variable, and references water-intake follow-up.

Shortcut inventory

The reviewed folder contains these 13 named Shortcuts:

  1. Combat Ready - Last 20 Lbs — primary shortcut entry point.
  2. Open Finch All — opens the Finch companion workflow.
  3. Get Morning Message — retrieves a morning prompt.
  4. Dynamic Morning Message — prepares a variable morning message.
  5. Get Milestone Message — retrieves milestone context.
  6. Log Discipline — collects and assembles the daily discipline record.
  7. Get Reflections Response — retrieves reflection input.
  8. Get Discipline Response — retrieves disciplined or undisciplined response values.
  9. Get Read Bible Prompt — retrieves the faith/read prompt.
  10. Discipline Http Request — centralizes the Notion API request body.
  11. Get Water Intake — retrieves water-intake completion data.
  12. Get Exercise Response — retrieves exercise completion data.
  13. Log Discipline Day V1 — earlier logging workflow retained in the folder.

Notion request structure

Discipline Http Request receives a dictionary, extracts values for Disciplined, Exercise, Water, Faith, Reflection, and Date, then builds a Notion page request.

The request body includes a date property, a Goal Tracker relation, and structured properties for Disciplined, Exercise Completed, Water Intake, Faith, and Reflection. The database identifier and relation identifiers are intentionally not published.

Application dependencies

  • Apple Shortcuts — runs the prompts, helper workflows, conditional logic, variables, and HTTP request.
  • Notion API — receives the structured daily page request.
  • Notion workspace and database — stores the discipline records and Goal Tracker relation.
  • Notion API integration permissions — required to access the target database.
  • Apple Calendar or date context — useful for daily scheduling and date-based accountability, though the reviewed request body carries its own Date value.
  • Finch — referenced by Open Finch All as part of the surrounding accountability workflow.

Intended benefit

Reduce the mental overhead of repeating a daily checklist, make completion signals consistent, and preserve a searchable record of discipline, exercise, water, faith, reflections, and dates.

The logs also powered a Notion Chart built from the recorded data. Seeing the metrics made effort visible over time and forced a more honest assessment of what I was—or was not—actually completing.

Evidence & current limits

The Shortcut folder and editor review verify the names and behaviors described here. Public screenshots, exported Shortcuts, synthetic request/response examples, and a full run history have not yet been attached.

Next proof-of-work step: show one synthetic daily run from prompt collection through the Notion request while keeping database IDs, relation IDs, API secrets, and personal reflections private. This page documents the workflow; it does not claim a measured adherence improvement.
