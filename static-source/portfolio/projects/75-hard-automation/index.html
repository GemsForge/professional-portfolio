75 Hard automation

A repeatable daily workflow that turns a rigid challenge into visible prompts, checks, and progress records.

Independent workApple Shortcuts · Reminders · Calendar · Progress tracking

On this page

The frictionThe technical solutionEvidence & limits

The friction

A challenge with several daily requirements creates repeated cognitive overhead: remembering each rule, recording completion, and noticing unfinished items before the day closes. Manual tracking can become another task to manage.

The technical solution

I translated the daily requirements into an automation-oriented workflow. Prompts and records make the checklist repeatable while leaving the completion decision with the person using it.

  1. Present the day’s required activities in a consistent sequence.
  2. Capture completion or follow-up notes.
  3. Write progress to the chosen Apple-native tracking tools.
  4. Use the day and streak context to make progress visible.

Evidence & current limits

The portfolio currently documents the workflow concept and intended behavior. The Shortcut export, screenshots, and a full run history have not yet been attached, so no completion rate or adherence improvement is claimed.

Next proof-of-work step: publish a redacted Shortcut walkthrough and a sample day using demo data. This automation supports accountability; it does not replace medical, fitness, or mental-health advice.
