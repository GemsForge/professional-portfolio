Application responsibilities

The system is divided across the shortcut interface, reusable request helpers, Notion data, and date context.

Hair Care Log system responsibilities
Tool / componentResponsibility
Apple ShortcutsRuns the 18 workflows, prompts, routing, API requests, result parsing, and reusable property helpers.
Care MenuActs as the user-facing entry point and routes to logging, search, and supporting actions.
Log Hair Care / Log Hair RetieCollect and submit the details for a care activity or retie event.
Hair Care HTTP RequestCentralizes Notion API request behavior so helper shortcuts use a consistent integration path.
Search Care LogsQueries the Notion API, processes matching pages, and prepares recent entries for selection.
Notion API + hair-care databaseStore the source-of-truth records and return page properties, dates, URLs, and related details.
Apple CalendarProvides surrounding date context for care tracking and review; it is separate from the Notion record store.
Integration permissions + property schemaAllow the integration to access the database and keep the property helpers aligned with Notion field names and types.
