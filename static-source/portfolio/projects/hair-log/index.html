Hair Care Log

An Apple Shortcuts system that records hair-care activity in Notion, uses Apple Calendar as part of the surrounding workflow, and retrieves prior entries through the Notion API.

Independent workApple Shortcuts · Apple Calendar · Notion API

On this page

The friction

Hair-care activities, products, styles, conditions, prices, and results are easy to forget or record inconsistently. Finding a previous entry also requires manually searching through a growing Notion log.

The technical solution

Built a modular Apple Shortcuts application connected to a Notion hair-care database. Care Menu is the user-facing entry point. It routes to logging, search, and reusable property helpers rather than placing every decision in one large Shortcut.

The search workflow calls the Notion API, processes returned pages in a loop, builds a title-to-details dictionary containing each log’s readable title, page URL, and date, presents recent entries for selection, and opens the selected Notion page. Apple Calendar is part of the application context for date-based care tracking and review.

Shortcut actions

The Hair Care Log folder contains these 18 named Shortcuts:

  1. Care Menu — central user-facing router.
  2. Log Hair Care — records a hair-care activity.
  3. Log Hair Retie — records a retie event.
  4. Search Care Logs — searches existing Notion records.
  5. Select Latest Log Entry — presents recent entries for selection.
  6. Hair Care HTTP Request — centralizes Notion API request behavior.
  7. Get Care Activity — retrieves the activity property.
  8. Get Products — retrieves products associated with a log.
  9. Get Product Images — retrieves product image data.
  10. Get Product Price — retrieves product price data.
  11. Get Product Type — retrieves product type data.
  12. Add Pros To Product — adds product advantages to a record.
  13. Add Cons To Product — adds product drawbacks to a record.
  14. Get Hair Style — retrieves the hair-style property.
  15. Get Hair Style 2 — supports a second style value or style branch.
  16. Get Initial Condition — retrieves the starting condition.
  17. Get Completed Condition — retrieves the ending condition.
  18. Get Process Type — retrieves the process classification.

Application dependencies

  • Apple Shortcuts — runs the menu, logging, search, parsing, selection, and property-retrieval workflows.
  • Apple Calendar — provides date-based context for care activity tracking and review.
  • Notion API — searches the care-log database, reads page properties, and opens the selected page.
  • Notion workspace and hair-care database — stores the searchable source-of-truth records.
  • Notion API integration — must have access to the relevant database and pages.
  • Consistent Notion property names and types — required by the property helper Shortcuts.
  • Secure API-key handling and permissions — required for authenticated requests without exposing credentials.

Intended benefit

Reduce the cognitive load of maintaining a long-term hair-care record, make previous entries easier to retrieve, and create more consistent data for reviewing products, routines, styles, and outcomes.

Evidence & current limits

The reviewed workflow documentation establishes the 18-Shortcut structure and the Notion search behavior described here. Public screenshots, exported Shortcuts, synthetic API request and response examples, and the database schema with private identifiers removed have not yet been attached.

Next proof-of-work step: show one new care entry, one Notion search, and retrieval of a previous log while keeping API keys, page IDs, and personal records private.
